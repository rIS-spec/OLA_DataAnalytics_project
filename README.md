# OLA Data Analytics Project

An end-to-end data analytics project on **OLA ride-hailing data** — from raw data processing to an interactive Power BI dashboard with multiple analytical views.

---

## Project overview

This project analyses OLA ride data to uncover insights about booking trends, revenue patterns, cancellation behaviour, vehicle performance, and customer/driver ratings.

---

## Dashboard views

The Power BI report contains 5 dashboard pages:

| Page | Focus |
|------|-------|
| Overall | High-level KPIs — total bookings, revenue, ride volume |
| Vehicle type | Performance breakdown by vehicle category |
| Revenue | Revenue trends over time and by segment |
| Cancellation | Cancellation rates, reasons, and patterns |
| Ratings | Customer and driver rating distributions |

---

## Tech stack

| Tool | Purpose |
|------|---------|
| Power BI | Dashboard creation and visualisation |
| SQL | Data querying and transformation |
| Python / Excel | Data cleaning and preparation |

---

## Key insights explored

- Which vehicle types generate the most revenue?
- What are the peak booking hours and days?
- What are the top reasons for ride cancellations?
- How do customer ratings vary across vehicle types?
- What is the relationship between ride distance and rating?
